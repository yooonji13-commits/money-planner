# 실행과 확인

## 필요한 것

- **Node** — 문법 검사와 확인용 정적 서버에만 쓴다. 앱 자체는 Node가 필요 없다.
  (확인된 버전: 24)
- **최신 브라우저** — 앱은 `crypto.subtle`, `fetch`, `Object.assign`, `String.padStart`,
  `Array.prototype.find`를 쓴다.
- 설치할 패키지는 **없다.** `npm install` 할 것이 없다.

## 앱 띄우기

### 확인·개발할 때

`localStorage`가 필요하므로 **반드시 http 주소로** 띄운다. 파일을 그냥 열면(`file://`)
`localStorage`가 막혀 저장·가져오기·동기화가 전부 동작하지 않는다.

```bash
node .claude/serve.js
```

`http://localhost:4173` 에서 앱이 뜬다. 포트를 바꾸려면 `PORT=4183 node .claude/serve.js`.

이 서버는 저장소 루트를 그대로 내주는 20줄짜리 정적 서버이고, **없는 경로에는 404를 준다.**
그 성질을 확인 작업에서 쓴다(아래 "확인용 데이터 넣기").

Claude Code 안에서는 `.claude/launch.json`에 `money-planner`라는 이름으로 등록돼 있어 미리보기
창으로 바로 띄울 수 있다.

### 실제로 쓸 때

정적 호스팅에 `index.html`, `favicon.png`, `apple-touch-icon.png`를 올리면 끝이다. 빌드 단계가
없다.

아이폰에서는 사파리로 열어 **홈 화면에 추가**해서 쓴다. 그러면 주소창 없이 앱처럼 뜬다
(메타 태그가 그렇게 설정돼 있다).

## 문법 검사

합치기 전에 반드시 통과해야 한다.

```bash
node -e "const fs=require('fs');const h=fs.readFileSync('index.html','utf8');const m=[...h.matchAll(/<script>([\s\S]*?)<\/script>/g)];fs.writeFileSync(process.argv[1],m.map(x=>x[1]).join('\n;\n'));console.log('blocks:',m.length);" ./mp-syntax-check.js && node --check ./mp-syntax-check.js && echo "문법 정상" && rm -f ./mp-syntax-check.js
```

`blocks: 1`과 `문법 정상`이 나와야 한다.

- `blocks`가 1이 아니면 `<script>` 블록이 늘거나 줄었다는 뜻이다. CDN에서 불러오는 스크립트는
  `src` 태그라 뽑히지 않으므로, 앱 코드 한 덩어리만 나오는 것이 정상이다.
- 마지막에 임시 파일을 지우는 것까지가 한 명령이다. 저장소에 남기지 않는다.
- **순서 주의:** 뽑아내기가 먼저고 검사가 나중이다. 반대로 하면 이전 실행이 남긴 낡은 파일을
  검사하게 된다.

## 확인용 데이터 넣기

앱은 열 때 읽은 내용을 정규화해 그 자리에 되쓰고, 닫힐 때 입력 중이던 값을 마무리 저장한다.
그래서 데이터를 넣고 새로고침하면 **앱이 들고 있던 이전 상태가 방금 넣은 값을 덮어쓴다.**

순서를 이렇게 한다.

1. 같은 출처의 **앱이 아닌 주소**로 이동한다 — 예: `http://localhost:4173/__seed`
   (서버가 404를 주므로 앱 코드가 실행되지 않는다).
2. 거기서 `localStorage`에 확인용 데이터를 넣는다.
3. `http://localhost:4173/index.html` 로 이동한다.
4. **데이터가 실제로 들어갔는지 먼저 읽어 확인**하고 나서 판단한다.

`localStorage` 키는 다음과 같다.

| 키 | 무엇 |
|---|---|
| `mp_data_v1` | 가계부 전체 (JSON) |
| `mp_personal_pw_v1` | 개인 탭 비밀번호 — 비밀번호 문자열의 SHA-256 16진 해시 |
| `mp_sync_code` | 이 기기가 쓰는 6자리 동기화 코드 |
| `mp_last_saved_at` | 마지막 저장 시각 (ISO 문자열) |
| `mp_data_v1_unreadable`, `..._1`, `..._2` … | 읽지 못한 원문의 사본 |

비밀번호 해시를 만들려면:

```bash
node -e "console.log(require('crypto').createHash('sha256').update('1234').digest('hex'))"
```

## 상황을 일부러 만들어 보는 법

| 확인할 상황 | 만드는 방법 |
|---|---|
| 저장된 원문이 깨진 상태 | `mp_data_v1`에 JSON이 아닌 문자열을 넣고 앱을 연다 |
| 저장 공간이 꽉 찬 상태 | `localStorage.setItem`을 가로채 `mp_data_v1` 쓰기에서 예외를 던지게 한다 |
| 화면 그리기 실패 | 탭 그리기 함수 하나가 예외를 던지도록 사본을 고쳐 띄운다 (확인 뒤 되돌린다) |
| 앱이 백그라운드로 감 | `document.hidden`을 강제로 참으로 만들고 `visibilitychange`를 보낸다. `pagehide`도 따로 보내 본다 |
| 잠긴 상태 | `mp_personal_pw_v1`에 해시를 넣고 앱을 연다 |
| 동기화 코드 겹침·인터넷 끊김 | 아래 참고 |

**동기화를 시험할 때는 실제 클라우드를 쓰지 않는다.** `index.html`에 실제 Supabase 주소와 키가
박혀 있어서, 실제 코드로 연결하면 실제 가계부가 내려오고 그 뒤 저장이 휴대폰 데이터를 덮어쓴다.

대신 이렇게 한다.

1. `index.html` 사본을 만들어 CDN `<script src=...>` 줄을 지운다.
2. 그 자리에 `window.supabase.createClient`를 흉내내는 대역을 심어, `.from().select()`와
   `.upsert()` 호출을 기록하고 원하는 결과를 돌려주게 한다.
3. 겹침·전부 겹침·조회 실패·쓰기 실패를 각각 만들어 **몇 번 조회하고 몇 번 쓰는지**를 센다.
4. 브라우저 네트워크 기록에 실제 주소로 나간 요청이 없는지 확인한다.

## 확인해야 할 동작

동작을 바꿨으면 브라우저에서 직접 눌러 확인하고, 무엇을 눌렀고 무엇이 보였는지 남긴다. 화면
크기는 **375×812(휴대폰 폭)**로 맞추고 본다 — 실제 사용 환경이다.

최소한 아래는 본다.

- 다섯 탭이 모두 그려진다 (깨진 데이터를 섞어 넣었을 때도).
- 금액칸에 마이너스를 넣었을 때 입력칸·화면·저장값이 모두 규칙대로다.
- 숫자를 치는 동안 키패드가 내려가지 않는다(입력칸에 커서가 남는다).
- 날짜를 지우다 중간 상태로 손을 떼도 이미 저장된 날짜가 사라지지 않는다.
- 이월 두 줄이 짝으로 움직인다.
- 잠긴 상태에서 내보내기·가져오기가 막히고, 동기화·계산기는 된다.
- 가로 스크롤이 생기지 않는다.
- 자바스크립트 오류가 없다.

## 배포

브랜치를 `main`에 합치고 정적 호스팅에 올린다. 되돌릴 때는 이전 커밋의 `index.html`을 다시
올리면 된다 — 파일 하나라 부분 롤백이 없다.
