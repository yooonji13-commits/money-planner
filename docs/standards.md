# 규칙

어기면 앱이 깨지거나 데이터가 사라진다. 취향은 규칙이 아니다.

## 파일과 의존성

- **`index.html` 한 파일을 유지한다.** 파일을 쪼개지 않고, 빌드 도구·번들러·패키지 관리자를
  도입하지 않는다. 브라우저로 파일을 열면 그대로 동작하는 상태가 유지되어야 한다.
  - 어겼는지 판단: 저장소에 `package.json`, 번들러 설정, `dist/` 같은 산출물 디렉터리가 생겼는가.
- **새 외부 의존성을 추가하지 않는다.** 현재 외부에서 불러오는 것은 CDN의 Supabase 클라이언트
  하나뿐이다.
- **`.claude/`는 저장소에 들어가지 않는다**(`.gitignore`). 확인용 정적 서버 스크립트와 실행 설정을
  그 안에 둔다. 작업용 임시 문서를 두는 폴더도 같이 제외돼 있다.

## 코드 형태

- **ES5 수준으로 쓴다.** `var`, `function` 선언, `.then()/.catch()`를 쓰고 `let`/`const`/화살표
  함수/`async`·`await`/클래스를 새로 들이지 않는다. 기존 코드 전체가 이 형태이며 섞이면 읽기
  어려워진다.
  - 어겼는지 판단: 앱 코드(`<script>` 안)에 `let `, `const `, `=>`, `async ` 가 있는가.
- **전체가 하나의 즉시 실행 함수 안에 있고 `"use strict"`가 걸려 있다.** 전역을 새로 만들지
  않는다. 원시값에 속성을 대입하면 조용히 무시되는 대신 오류가 된다는 점에 주의한다.
- **화면 요소는 `mp-` 접두 클래스를 쓴다.** 새 요소도 이 규칙을 따른다.
- **사용자에게 보이는 모든 문구는 한국어이고 말투는 `~해요`체다.**
- **동작은 `data-action` 값으로 구분하고 리스너는 `#mp-root`에 위임한다.** 개별 요소에 리스너를
  직접 붙이지 않는다 — 화면을 다시 그리면 사라진다.
  - 예외: 하단 탭바 버튼은 정적 요소라 각 버튼에 직접 붙어 있다.
- **삭제 동작의 이름은 `delete-`로 시작한다.** 클릭 처리 맨 앞이 이 접두를 보고 확인 창을 띄우므로,
  이 규칙을 따르면 새 삭제 기능에 자동으로 확인이 붙는다. 확인 문구는 `DELETE_CONFIRM_TEXT`에
  등록한다.

## 저장

- **`localStorage`에 직접 쓰지 않는다.** 반드시 `writeStorage()` / `readStorage()`를 지난다.
  직접 쓰면 저장 공간이 꽉 찼을 때 예외가 그대로 터져 같은 처리 안의 뒤따르는 화면 갱신이
  중단된다.
  - 어겼는지 판단: 앱 코드에 `localStorage.setItem` / `localStorage.getItem` 직접 호출이 있는가.
  - 예외 셋: `writeStorage`/`readStorage` 정의 자체, 읽지 못한 원문을 따로 보관하는 자리(성공
    여부를 스스로 판단해야 해서 감싸지 않는다), 그리고 저장된 원문을 처음 읽어 보는 자리(여기서
    실패하는 것이 곧 "읽을 수 없는 상태"의 판정이다).
- **가계부 상태 저장은 `saveState()` 하나만 쓴다.** 이 함수가 저장·시각 기록·클라우드 전송 예약을
  묶어 처리한다.
- **원문을 읽지 못한 상태(`storageUnreadable`)에서는 가계부를 저장하지 않고 클라우드로도 보내지
  않는다.** 이 상태를 우회해 쓰는 경로를 만들지 않는다. 유일한 예외는 가져오기 처리로, 백업
  파일로 되살리는 것이 이 상태를 벗어나는 방법이다.
- **기록을 지우지 않는다.** 데이터 정규화는 화면이 깨지지 않게 하는 것이 목적이며, 읽을 수 없는
  값은 안전한 값으로 바꾸되 줄 자체는 남긴다. 이미 저장된 값을 일괄로 변환하지 않는다.

## 데이터를 읽어들이는 길

- **들어오는 데이터는 모두 `normalizeState()` 하나를 지난다.** 기기 저장소·클라우드·백업 파일
  세 경로가 같은 함수를 쓴다. 경로마다 따로 검사 코드를 만들지 않는다.
- **비밀번호 해시는 상태(`state`)에 넣지 않는다.** 기기 전용 키에만 둔다. `state`에 들어가면
  클라우드와 내보내기 파일로 새어 나간다.
- **어느 탭·몇 월을 보고 있는지는 원격 값으로 덮지 않는다.** 기기별 화면 상태다.

## 화면 갱신

- **입력 중에 화면을 통째로 다시 그리지 않는다.** 숫자가 바뀔 때는 해당 항목의 부분 갱신 함수를
  쓴다. 통째로 그리면 입력칸 노드가 교체되어 아이폰에서 키패드가 내려간다.
  - 어겼는지 판단: `input` 리스너 경로나 잠금 화면 입력 처리에서 `render()`를 부르는가.
- **날짜칸은 치는 도중에 저장하지 않는다.** 중간 상태는 전부 무효라 저장하면 이미 적어둔 날짜가
  지워진다. 저장은 손을 뗀 시점에, 유효할 때만 한다.
- **화면 그리기는 `render()`로 들어가고 실제 그리기는 `drawApp()`에 있다.** 그리기 실패는
  `render()`가 잡아 안내 화면으로 대체한다. `drawApp()`을 직접 부르지 않는다 — 오류 보호를
  건너뛴다.
- **안내 화면을 그리다 또 실패할 때를 대비한 빗장(`renderingErrorScreen`)을 없애지 않는다.**
  없으면 무한히 되돌게 된다.

## 목록 정렬

- **정렬은 `txListComparator()`를 쓴다.** 개인 탭·생활비·저축 세 목록이 같은 비교 규칙을 공유한다.
- **정렬 기준값을 뺄셈으로 비교하지 않는다.** 기준값이 없는 예전 기록에서 결과가 숫자가 아니게
  되어 비교 자체가 망가진다.

## 확인 게이트 — 합치기 전에 통과해야 하는 것

이 프로젝트에는 테스트 프레임워크가 없다. 대신 아래 둘을 통과해야 한다.

**1. 문법 검사 (기계)**

```bash
node -e "const fs=require('fs');const h=fs.readFileSync('index.html','utf8');const m=[...h.matchAll(/<script>([\s\S]*?)<\/script>/g)];fs.writeFileSync(process.argv[1],m.map(x=>x[1]).join('\n;\n'));console.log('blocks:',m.length);" ./mp-syntax-check.js && node --check ./mp-syntax-check.js && echo "문법 정상" && rm -f ./mp-syntax-check.js
```

`blocks: 1`과 `문법 정상`이 나와야 한다. 뽑아낸 임시 파일은 지운다(저장소에 남기지 않는다).
단일 파일이라 문법이 깨지면 앱이 백지로 뜬다 — 부분 실패가 없다.

**2. 브라우저 확인 (사람이 눌러서)**

`localStorage`가 필요하므로 **반드시 http 주소로 띄운다.** `file://`에서는 `localStorage`가
막혀(SecurityError) 저장과 관련된 모든 확인이 무의미해진다. 확인 절차는 운영 문서에 있다.

바꾼 동작마다 "무엇을 눌렀고 무엇이 보였는지"를 남긴다. 통과하지 못한 항목을 통과한 것처럼
적지 않는다.

## 커밋

- **커밋 메시지는 한국어다.** 첫 줄에 무엇을 했는지 짧게, 빈 줄 뒤 본문에 왜 그렇게 했는지를
  적는다. 기존 이력이 이 형태다.
- **`main`에 직접 커밋하지 않는다.** 작업은 브랜치에서 하고 합치기는 사용자가 결정한다.

## 바꾸지 않기로 정해진 것

아래는 버그처럼 보이지만 **사용자가 그대로 두기로 정한 것**이다. 지나가다 눈에 걸려도 고치지
않는다. 고쳐야 할 이유가 생겼다면 사용자에게 먼저 묻는다.

- **저축 탭 집안행사비용이 순저축에 더해지는 계산.** 이름이 비용이라 빼야 할 것처럼 보이지만
  더하는 것이 맞다.
- **동기화 코드 6자리.** 늘리지 않는다.
- **두 기기 동시 수정 시 나중에 저장한 쪽이 이기는 동작.**
- **코드로 처음 연결할 때 확인 창이 없는 동작.**
- **내역 날짜를 다른 달로 고쳐도 원래 달에 남는 동작.**
- **달을 넘겨보기만 해도 빈 달 묶음이 생기는 동작**(`getLivingMonth` 등이 읽으면서 만든다).
- **쓰이지 않는 상태 필드 `savingsExpenses`.** 지우지 말고 통과만 시킨다.
